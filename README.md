- [`6/`](https://iontiger.github.io/motion/6/) 서로 다른 성공 방식 · 대한치과의료관리학회 11월 종합학술대회 홍보 (iontiger의 노래 ‘잘되는 치과는 무엇이 다를까’, 96.5 BPM, 무작위 키네틱 가사 뒤로 포스터의 여섯 연자·세션·일정이 가사에 맞춰 튀어나옴)

- 사이트: https://iontiger.github.io/motion/

## 작품

- [`1/`](https://iontiger.github.io/motion/1/) 현대해상 투자포인트 모션그래픽 (128 BPM)
- [`2/`](https://iontiger.github.io/motion/2/) 덴포토 마을의 비밀 · 게임 4편 홍보 영상 (100 BPM, 파스텔톤)
- [`3/`](https://iontiger.github.io/motion/3/) 10월, 흔들리지 말아야 할 이유와 확인해야 할 것들 (120 BPM, 차트·캘린더, 브레이크 7곳)
- [`4/`](https://iontiger.github.io/motion/4/) 반도체의 계절 · 한국 EWY vs 대만 EWT (iontiger의 노래에 가사 자막과 그래픽을 맞춤, 103 BPM, 네온 다크톤)
- [`5/`](https://iontiger.github.io/motion/5/) 실적의 계절 · 키네틱 가사 (iontiger의 노래, 101 BPM, 가사가 비트에 맞춰 위·가운데·아래에 밑줄·형광펜·크기조절·빨랫줄·줌아웃 등 무작위 효과로 등장)
- [`6/`](https://iontiger.github.io/motion/6/) 서로 다른 성공 방식 · 대한치과의료관리학회 11월 종합학술대회 홍보 (iontiger의 노래 ‘잘되는 치과는 무엇이 다를까’, 96.5 BPM, 무작위 키네틱 가사 뒤로 포스터의 여섯 연자·세션·일정이 가사에 맞춰 튀어나옴)
- [`7/`](https://iontiger.github.io/motion/7/) 잘되는 치과는 무엇이 다를까 · 3D 디스코 (iontiger의 노래, 105 BPM, three.js로 만든 디스코 무대 위에 입체 글자가 음절마다 떨어지고 돌며 등장, 치아 모양 미러볼·발광 타일 바닥·조명 빔, 끝에 KADA 로고와 행사 안내)
- [`8/`](https://iontiger.github.io/motion/8/) 필름을 되감는다 · 키네틱 가사 (iontiger의 노래, 100 BPM, 4분 36초, 흑백 필름 영사: 리더 카운트다운, 줄마다 바뀌는 컷(자막·무성영화 인터타이틀·슬램·타자기 시나리오·필름 스트립·줌), 바람·잉크·얼음 훅, 거꾸로 감기다 피 흘리고 불타는 후렴, 색은 핏빛 하나)
- [`9/`](https://iontiger.github.io/motion/9/) 구명조끼부터 입혀 줘 · 카툰 키네틱 가사 (iontiger의 노래와 만화, 95 BPM, 3분 2초, 만화 컷과 흰 곰 캐릭터가 가족 모임·물속·수영장·연습 몽타주·산길·노을·호숫가를 지나고, 가사는 음절마다 스티커 글자로 톡 튀기·떨어지기·라벨·말풍선·나레이션 박스 등으로 등장, 후렴마다 아이들에게 구명조끼가 떨어짐)

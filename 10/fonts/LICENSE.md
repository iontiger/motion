# Fonts

All four files are subsets (only the glyphs this page uses), converted to WOFF2, and all are released under the SIL Open Font License 1.1 (https://openfontlicense.org). Re-subset with `tools/subset-font.py` after changing any text.

- `pretendard-sub.woff2`: Pretendard Variable 1.3.9. Copyright (c) 2021, Kil Hyung-jin, with Reserved Font Name Pretendard.
- `hahmlet-sub.woff2`: Hahmlet (variable, wght 100–900). Copyright 2021 The Hahmlet Project Authors.
- `nanumpen-sub.woff2`: Nanum Pen Script. Copyright (c) 2010 NAVER Corporation.
- `fraunces-italic-sub.woff2`: Fraunces Italic, pinned to SOFT 100 / WONK 1 / opsz 72 (wght 500–900 kept). Copyright 2018 The Fraunces Project Authors.

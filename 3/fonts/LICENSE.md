# Fonts

`pretendard-sub.woff2` is a subset of Pretendard Variable 1.3.9 (only the glyphs this page uses), converted to WOFF2.
Pretendard is released under the SIL Open Font License 1.1 (https://openfontlicense.org).
Copyright (c) 2021, Kil Hyung-jin, with Reserved Font Name Pretendard.

To regenerate after you change on-screen text, run `python3 tools/subset-font.py <PretendardVariable.woff2>` (needs `fonttools` and `brotli`).
